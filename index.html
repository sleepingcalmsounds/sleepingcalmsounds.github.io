GSync (Personal)

This page is the application homepage for a personal-use OAuth client named "GSync".

What this application does

The owner of this site uses the GSync plugin for Obsidian to synchronize their personal notes between their own devices (such as an iPhone) and a folder in their own Google Drive. This OAuth client exists solely so that the plugin, running on the owner's own devices, can sign in to the owner's own Google account and read and write files inside the single Google Drive folder the owner configured for note synchronization.

Personal use only

This application is not a public service. It is not distributed to other users, it has no other users, and no one else's data is accessed, stored, or processed. Files move only between the owner's devices and the owner's own Google Drive.
