Privacy Policy

Last updated: 2026-11-02

This privacy policy describes how the personal-use OAuth application "GSync" (the "Application") handles Google user data. The Application is operated by an individual for their own personal use only.

Data accessed

The Application is used together with the GSync plugin for Obsidian. Through the Google Drive API, the plugin accesses files and folders inside the single Google Drive folder that the owner configured for synchronizing their personal Obsidian notes. The Application requests the Google Drive scope (https://www.googleapis.com/auth/drive) so the plugin can also see note files that were placed in that folder by other tools the owner uses.

How the data is used

The accessed data is used only to synchronize the owner's own notes between the owner's devices and the owner's Google Drive: uploading notes changed on a device, downloading notes changed in Drive, and reflecting deletions. The data is never used for advertising, analytics, or any other purpose.

Storage

Note files are stored only in the owner's Google Drive and on the owner's own devices. The OAuth refresh token is stored only on the owner's devices, in the plugin's local data file. No server operated by the owner or by any third party receives or stores the data.

Sharing

Google user data accessed through the Application is not shared with, sold to, or transferred to any third party.

Revoking access

Access can be revoked at any time from the Google Account permissions page (https://myaccount.google.com/permissions) by removing the Application. Removing access stops all synchronization.

Contact

The owner can be reached at the user support email shown on the application's OAuth consent screen.
